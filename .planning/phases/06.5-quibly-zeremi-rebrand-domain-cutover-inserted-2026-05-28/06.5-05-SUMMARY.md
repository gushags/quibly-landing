## Decisions Made

- Test files (branding.test.ts, brand-paint.spec.ts) added to EXCLUDE_FILES in the guard because they contain denylist patterns as regex literals — the same reasoning as the script's own self-exclusion
- privacy/page.tsx excluded: the "Name change notice" paragraph is legally required GDPR Art-13 content that explicitly names both brands; it must stay
- `brand` path segment added to EXCLUDE_DIRS to suppress false positive from public/brand/zeremi/README.md which documents the Quibly gradient origin for historical reference
- vitest.config include extended with `tests/*.test.{ts,tsx}` (matching .test. but not .spec.) so Playwright spec files at tests/ root are not accidentally loaded by vitest
