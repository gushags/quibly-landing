Per CONTEXT.md `<decisions>`, ports use one of four modes:
- **verbatim** — byte-for-byte copy (e.g., `lib/utils.ts` per CD-07; `quibs-icon.tsx` per D-01)
- **verbatim-minus-X** — copy with one allowed deviation (e.g., `globals.css` minus `@plugin "@tailwindcss/typography"` per D-04)

- **hybrid** — `npx shadcn add` then overwrite with `marketing-app` copy (CD-08 for the five UI components)
- **new** — no in-repo analog (`.gitleaks.toml`, custom ESLint rule banning raw `process.env.`, `lib/env.ts` Zod schema)

import { QuibsIcon } from '@/components/quibs/quibs-icon'

interface QuibsAvatarProps {
  size: 'message' | 'header' | 'fab'
  inverted?: boolean
  className?: string
}

const SIZE_CONFIG = {
  message: { container: 'h-7 w-7 rounded-lg', icon: { width: 16, height: 19 } },
  header: { container: 'h-9 w-9 rounded-lg', icon: { width: 22, height: 26 } },
  fab: { container: 'h-14 w-14 rounded-full', icon: { width: 28, height: 33 } },
} as const

export function QuibsAvatar({ size, inverted = false, className }: QuibsAvatarProps) {
  const { container, icon } = SIZE_CONFIG[size]
  const palette = inverted
    ? 'bg-white text-primary'
    : 'bg-gradient-to-br from-primary to-[#14b8a6] text-white'
  return (
    <div className={cn('flex items-center justify-center', container, palette, className)}>
      <QuibsIcon width={icon.width} height={icon.height} />
    </div>
  )
}

const ALLOWLIST_FRAGMENTS = ['/lib/env.ts']

          node.object.name === 'process' &&
          node.property.type === 'Identifier' &&

### CSS-var → Tailwind-utility two-hop indirection

**Source:** `marketing-app/app/layout.tsx:42` + `marketing-app/app/globals.css:11–14`
**Apply to:** Any new font / color / radius token

Pattern:
1. `next/font/google` exposes a CSS var (e.g., `variable: "--font-quicksand"`)
2. `<html className={`${quicksand.variable} ...`}>` lands the var on `<html>`
3. `globals.css` `@theme inline` maps `--font-heading: var(--font-quicksand)`
4. Tailwind utility `font-heading` resolves through both hops

Breaking any link breaks all four. The smoke-test page validates the full chain end-to-end (D-12).
