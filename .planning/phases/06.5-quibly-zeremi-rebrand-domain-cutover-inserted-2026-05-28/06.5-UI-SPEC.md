## Typography Contract

### Font Variables After Rebrand

```css
/* app/globals.css — single-line change */

--font-heading: var(--font-quicksand);

/* AFTER: */
```

```typescript

const breeSerif = Bree_Serif({
  subsets: ["latin"],

  display: "swap",

// <html> className:
// `${breeSerif.variable} ${figtree.variable} h-full antialiased`
```

### Type Scale (unchanged from Phase 2 baseline — only family swaps)

| Role    | Size  | Weight   | Line Height | Font family   | CSS utility         |
|---------|-------|----------|-------------|---------------|---------------------|
| Display | 36px  | 400      | 1.15        | Bree Serif    | `font-heading`      |
| Heading | 24px  | 400      | 1.2         | Bree Serif    | `font-heading`      |
| Sub-head | 18px | 600      | 1.4         | Figtree       | `font-sans font-semibold` |
| Body    | 16px  | 400      | 1.5         | Figtree       | `font-sans`         |
| Label   | 14px  | 500      | 1.4         | Figtree       | `font-sans font-medium text-sm` |
| Legal/small | 12px | 400  | 1.6         | Figtree       | `font-sans text-xs` |

Notes:
- Bree Serif is weight 400 only. There is no weight 600, 700 for this font. The `font-semibold` or `font-bold` class on a Bree Serif element will silently render weight 400 — do not request those weights.
- `font-heading` Tailwind utility resolves via `--font-heading` → `--font-bree-serif`. All existing `font-heading` consumers automatically pick up Bree Serif with zero per-component changes.
- Figtree weights (400, 500, 600, 700) are unchanged from Phase 1.

## Favicon / App Icon Contract

### `app/icon.tsx`

Current implementation uses `ImageResponse` to composite a background + `public/quibs-icon.png`.

After rebrand: The Zeremi square-chip PNGs are already fully composited (white Z on teal gradient background). Options in preference order:

1. **Preferred:** Replace `icon.tsx` with the static Next.js App Router convention — place `public/brand/zeremi/png/zeremi-icon-square-32.png` as `app/icon.png` directly. Next.js App Router serves `app/icon.png` automatically as the favicon. This removes the `ImageResponse` wrapper entirely.
2. **Fallback:** Keep `ImageResponse` but simplify to render the pre-composited PNG directly as `<img>` with no additional background compositing. Size: 32×32.

Warning: Do NOT double-composite the PNG (teal square on another teal square background). The brand PNGs have the gradient baked in.

### `app/apple-icon.tsx`

Same pattern. Use `zeremi-icon-square-180.png` (180×180). Either static file (`app/apple-icon.png`) or simplified `ImageResponse`.

### Email-Client Font Fallback Stack

Bree Serif is not reliably available in email clients. The welcome email's HTML `font-family` for the wordmark area uses:

```
font-family: 'Bree Serif', Georgia, 'Times New Roman', serif;
```

This provides: Bree Serif (if loaded) → Georgia (common webmail serif) → Times New Roman (universal fallback) → generic serif.

The wordmark is a rasterized PNG, so the fallback stack only applies to surrounding copy text that references the heading font, not the wordmark image itself.

## CI Guard Contract
