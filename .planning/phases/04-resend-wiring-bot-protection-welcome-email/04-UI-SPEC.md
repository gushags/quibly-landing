## Color

### Web UI (Inherited — Phase 1 tokens, unchanged)

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `--background`: `oklch(1 0 0)` = `#ffffff` | Page background, form surface |
| Secondary (30%) | `--secondary`: `oklch(0.97 0 0)` ≈ `#f7f7f7` | Muted text zones, input borders |
| Accent (10%) | `--primary`: `oklch(0.6002 0.1038 184.704)` ≈ `#0D9488` teal | See reserved list below |
| Destructive | `--destructive`: `oklch(0.577 0.245 27.325)` ≈ `#dc2626` | Inline field validation errors only |

Accent reserved for:
- Hero CTA button (`size="hero"`, `variant="default"`)
- Secondary CTA button (`size="hero"`, `variant="default"`)
- Success `CircleCheck` icon (`text-primary`)
- Focus ring on all interactive elements (`--ring`)
- No other elements

### Email Template (new surface)

Email clients do not support oklch. Use hex equivalents only.

| Role | Hex | Usage |
|------|-----|-------|
| Header strip background | `#0D9488` | Teal brand header (matches `--primary` hex) |
| Header text | `#ffffff` | Wordmark on teal strip |
| Email background | `#ffffff` | Full email background |
| Body text (primary) | `#404040` | Paragraph text |
| Body text (secondary) | `#737373` | Footer, legal, fallback URL |
| Divider / border | `#e5e5e5` | HR separator |
| Unsubscribe link | `#737373` underlined | Footer link — same weight as footer text |

No teal CTA button in the waitlist welcome email. The D-01 locked draft is a
founder-note text email — no "Open dashboard" style CTA button. The only link
elements are the unsubscribe link and postal address / footer.

## Interaction Contract

### Web UI (Inherited — Phase 3)

No changes to the `<WaitlistForm>` Client Component. All interaction states
(idle, pending, success, error) are locked per Phase 3 D-10.

### Phase 4 Backend Interactions (no new UI states)

| Event | Web UI Response | Notes |
|-------|----------------|-------|
| Rate-limit hit | Silent success (D-03) | Identical to real success; no toast, no inline error |
| Disposable domain | Silent success (D-03) | Identical to real success |
| Duplicate contact | Success (D-05) | No welcome email; on-page block unchanged |
| Real Resend error | Error toast via existing sonner path | Inherited Phase 3 D-12 |
| Welcome email failure | Silent to user; server `console.error` + `track('welcome_email_send_error')` | EMAIL-08 |

### Unsubscribe Route (`app/unsubscribe/route.ts`)

- `POST` — RFC 8058 one-click; processes unsubscribe, returns HTTP 200
- No user-facing HTML page required in Phase 4 (deferred per CONTEXT §Deferred)
- If a `GET` handler is added for link-click fallback: returns plain "You have been unsubscribed." text response at 200; no styling required

## Accessibility Contract (Inherited + Email)

### Web UI (Inherited)

- All interactive elements have visible focus ring (`outline-ring/50` from `globals.css`)
- Success block uses `role="status"` + `aria-live="polite"` (Phase 3)
- Error field uses `aria-invalid` + `aria-describedby` (Phase 3)
- `prefers-reduced-motion` honored (Phase 2)

### Email Template

- All images: none used in Phase 4 waitlist email (text-only body)
- Links: descriptive text ("Unsubscribe", not "click here")
- Adequate color contrast: `#404040` on `#ffffff` = 9.7:1 (WCAG AAA); `#737373` on `#ffffff` = 4.6:1 (WCAG AA)
