|-------|----|----------|---------------|

| sm | 8 | `gap-2`, `p-2` | Microcopy ↔ CTA gap, tight inline content |
| md | 16 | `gap-4`, `p-4` | Default element spacing inside cards / blocks |
| lg | 24 | `gap-6`, `px-6` | Mobile horizontal page padding (`px-6`); inter-paragraph rhythm |

Page wrapper container (D-17): `max-w-6xl mx-auto px-6 md:px-8`. Inner-tighter prose constraint (D-15, D-05): `max-w-prose` (≈65ch / ~600px).

Exceptions (locked, not arbitrary):
- **Hero CTA pill padding:** `14px 36px` literal (design-system §1 `.btn-hero` row, confirmed at line 204 / line 210 of `2026-04-14-quibly-design-reference.html`). Tailwind: `px-9 py-3.5` (closest 4-multiple match: 36/14 ≈ 9/3.5). Encoded in the `size="hero"` CVA variant — see Component Inventory.

- **`max-w-prose`** = Tailwind default `65ch` ≈ 600–620px depending on body font metrics. Acceptable; do not redefine.

| Destructive | `--destructive` `oklch(0.577 0.245 27.325)` | **Not used in Phase 2.** No destructive actions ship this phase (no form, no delete, no unsubscribe link yet). Token reserved for Phase 3+. |

**Accent reserved for** (explicit list — nothing else gets teal in Phase 2):
1. Hero mascot 88px rounded-square gradient background (D-02)
2. Hero CTA pill (`<Button size="hero" variant="default">` → `bg-primary`)
3. Secondary CTA pill (same `<Button size="hero" variant="default">` per D-10)
4. WhyQuibly three lucide icons (`text-primary`, stroke 1.75, size 24–28px) (D-14)
5. Footer "Quibly" wordmark text (`text-primary`, Quicksand 700, 16px) (D-18)
6. Hero radial-gradient backdrop stops (low-opacity teal + warm amber; see "Decorative Posture" below) (D-22)

**Anti-uses (do NOT apply teal to any of these):**
- Hero H1 text — neutral `text-foreground` only (D-04)
- Body copy / sub-headline / founder paragraph — neutral
- Footer link hrefs (`/privacy`, `/terms`) — neutral `text-muted-foreground` with hover `text-foreground`; teal would compete with the wordmark
- Section background fills — flat white, no teal washes (D-22 specifies gradient only behind hero)
- WhyQuibly card labels (Quicksand 600) — neutral `text-foreground`
- Differentiator descriptions — neutral `text-muted-foreground`

**Decorative Posture — Hero radial gradient (D-22):**
- Implementation: a positioned `<div aria-hidden="true" className="pointer-events-none absolute inset-0 -z-10">` with `bg-[radial-gradient(...)]`, OR `bg-[radial-gradient(...)]` directly on the `<Hero>` `<section>`.
- Tuned stops (CD-01 — Claude's call):
  - First stop: teal `oklch(0.6002 0.1038 184.704 / 0.08)` from top-left at ~30% 20% with radius ~60% — ≤8% opacity so it reads as a tint, not a wash.
  - Second stop: warm amber `oklch(0.78 0.13 70 / 0.06)` from bottom-right at ~75% 80% — ≤6% opacity.
  - Final stop: `transparent` so the rest of the hero stays white-dominant.
  - Concrete utility: `bg-[radial-gradient(at_30%_20%,oklch(0.6002_0.1038_184.704_/_0.08),transparent_60%),radial-gradient(at_75%_80%,oklch(0.78_0.13_70_/_0.06),transparent_55%)]`
- The gradient does NOT animate, does NOT respond to scroll, does NOT respond to pointer (D-23).
- The gradient does NOT extend below `<Hero>`. `<PlaceholderFormSection>` and below render on flat `bg-background` white.
- Gradient must NOT cover the `<h1>` foreground enough to drop contrast below WCAG AA. At ≤8% opacity teal on white the H1's `text-foreground` retains AAA contrast — verified in plan QA.

**Color contrast ratios (must validate in plan):**
- Hero H1 `text-foreground` on white background: ≥7.0 (AAA)
- Sub-headline `text-muted-foreground` on white: ≥4.5 (AA)
- Microcopy `text-sm text-muted-foreground` on white: ≥4.5 (AA — applies because text is non-large)
- Hero CTA `text-primary-foreground` (white) on `bg-primary` (teal `#0D9488`): ≥4.5 (AA-large at 18px+; the pill text is 16px Figtree, must verify)
- Footer links neutral state: ≥4.5 on white
- WhyQuibly lucide icons (`text-primary` on white): not text — purely decorative — no contrast minimum (icon-only meaning is supplemented by adjacent text label)

### Responsive behavior (MOB-01..04)

- Layout is single-column on mobile (320–767px), with the WhyQuibly grid expanding to 3-column at `md:` (768px+) (D-13). All other sections remain single-column at every breakpoint.
- All interactive elements ≥48px tap target on mobile (MOB-02): hero CTA pill (~52px), secondary CTA pill (~52px), footer links (`py-2` lifts effective hit-area to ≥48px even at 14px font-size).
- Body text ≥16px on mobile (MOB-04): sub-headline `text-base` (16px), founder paragraph `text-base`, footer copy `text-sm` (14px). **Note:** footer copy at 14px is below the 16px MOB-04 floor. Per HTML5 Safari iOS the auto-zoom-on-focus behavior triggers only for `<input type="text">` ≤16px, NOT for static text. The MOB-04 requirement is about interactive `<input>` elements (Phase 3).
