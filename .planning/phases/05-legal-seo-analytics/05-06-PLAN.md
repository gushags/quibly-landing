<decision>
Use the same `public/quibs-icon.png` (360×360) for both /icon (32×32) and /apple-icon (180×180).
Satori downscales the PNG cleanly via the explicit width/height on the `<img>` element.
We do NOT generate a separate `public/quibs-icon-32.png` — empirically a 360→32 downscale of
a clean 2-color (white + transparent) PNG produces a sharp result, and the 32×32 surface
is small enough that any minor antialiasing softening is imperceptible at typical browser
tab DPI. This keeps the asset count to ONE shared PNG. If post-deploy the 32×32 looks
muddy in browser tabs, the planner for a follow-up gap can add a pre-sized 32×32 PNG.
</decision>

Full new file content:

```tsx
import { ImageResponse } from 'next/og'
import { readFile } from 'node:fs/promises'
import { join } from 'node:path'

export const runtime = 'nodejs'              // MUST be nodejs — Edge cannot use node:fs
export const size = { width: 32, height: 32 }
export const contentType = 'image/png'

/**
 * Renders the Quibs mascot (Q-face + two eye-dots) on the brand teal background.
 *
 * Source asset: public/quibs-icon.png (360×360, transparent bg, white mascot —
 * generated by scripts/rasterize-mascot.mjs from public/quibs-icon.svg).
 *
 * WHY PNG NOT SVG: Satori (the renderer behind next/og's ImageResponse) does not
 * support <img src=data:image/svg+xml;...> in @vercel/og 0.11.x. PNG via data URI
 * is supported. See app/opengraph-image.tsx and 05-05-SUMMARY.md for context.
 */
export default async function Icon() {
  const mascotPng = await readFile(join(process.cwd(), 'public/quibs-icon.png'))
  const mascotDataUri = `data:image/png;base64,${mascotPng.toString('base64')}`

  return new ImageResponse(
    (
      <div
        style={{
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          width: '100%',
          height: '100%',
          background: '#14a3a3',
        }}
      >
        {/* eslint-disable-next-line @next/next/no-img-element */}
        <img
          src={mascotDataUri}
          alt=""
          width={22}
          height={22}
          style={{ width: 22, height: 22 }}
        />
      </div>
    ),
    { ...size }
  )
}
```

Sizing rationale: 22×22 mascot inside the 32×32 frame leaves ~5px on each side — visually balanced for a small browser-tab icon. Matches the existing styled-Q "fontSize: 22" footprint the previous placeholder used.

Replace the file contents wholesale. Do not delete other unrelated files. Do not modify the file's exports (`runtime`, `size`, `contentType`) other than to keep them; the test at tests/seo.spec.ts:30-50 hits `/icon` and depends on those.
